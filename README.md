# DSCI 552 Homework 3: AReM Feature Extraction

This repository contains the completed Homework 3 analysis for the AReM human-activity time-series dataset.

## Contents

- `Yash_Desai_DSCI552_HW3_AReM_Explained.ipynb` — explanations, analysis code, and saved outputs for the required HW3 questions.
- `data/arem/` — the 88 AReM CSV recordings and the dataset documentation PDFs.
- `arem_instance_features.csv` — the 88-row feature table generated by the notebook.
- `requirements.txt` — Python packages needed to run the notebook.

## Questions covered

1. AReM dataset description and the prescribed train/test assignment (69 train, 19 test).
2. Research examples of time-domain features.
3. Extraction of seven summaries for each of six channels (42 features per recording).
4. Across-recording feature standard deviations and 90% bootstrap confidence intervals.
5. A reasoned selection of three features using one-way ANOVA F-statistics across the seven activity labels.
6. ISLR Exercise 3.7.4, parts (a)–(d).

The later binary and multiclass classification instructions in the assignment PDF are specified for Homework 4 and are not part of this HW3 submission.

## Run the notebook

Run these commands from the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab
```

Open `Yash_Desai_DSCI552_HW3_AReM_Explained.ipynb` and select **Run All**. The notebook reads the included extracted files under `data/arem/`, so it does not need the ZIP archive. It also supports extracting the ZIP if the extracted files are not present.

The notebook writes or refreshes `arem_instance_features.csv` in the repository root. It handles the dataset's minor formatting variations, including the whitespace-delimited `bending2/dataset4.csv`, two trailing-comma files, and the missing sensor reading in `sitting/dataset8.csv`.

## Dataset source

The AReM dataset is from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/366/activity+recognition+system+based+on+multisensor+data+fusion+arem). The required feature-extraction assignment is described in the course-provided HW3 PDF.
